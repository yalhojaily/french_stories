# Petit Carnet: دفتر الفرنسية الصغير

موقع لتعلّم أساسيات الفرنسية في شهر من خلال ٢٠ قصة قصيرة. عند الضغط على أي كلمة تظهر ترجمتها ويُسمع نطقها، ويمكن الاستماع إلى القصة كاملة مع تظليل كل كلمة لحظة نطقها.

## التشغيل

افتح `index.html` في المتصفح مباشرة، ولا حاجة لخادم.
إذا لم تولّد الصوت بعد، يعمل الموقع بصوت المتصفح المدمج.

## إضافة صوت ElevenLabs

```bash
pip install requests
cp .env.example .env              # ثم ضع مفتاحك في ملف .env
python tools/build.py --voices    # اختر صوتاً وضع معرّفه في .env
python tools/build.py --audio     # يولّد الصوت ويبني الموقع
```

- يولّد السكربت ملف mp3 لكل قصة مع توقيت كل حرف، وملفاً لكل كلمة منفردة في `audio/words/`.
- المنهج كاملاً نحو ١٠ آلاف حرف فقط.
- عند إعادة التشغيل لا يولّد إلا ما تغيّر، ولإعادة توليد كل شيء أضف `--force`.
- **المفتاح لا يدخل الموقع أبداً**، فهو يُستخدم في هذا السكربت على جهازك فقط.

## تعديل القصص أو إضافة قصص جديدة

القصص في `stories/week1.txt` إلى `week4.txt` بصيغة بسيطة موضحة في أول `week1.txt`:

```
> Je suis étudiante. | أنا طالبة.
Je = أنا
suis = أكون | l=être
étudiante = طالبة | n=المذكر: étudiant
```

بعد أي تعديل شغّل `python tools/build.py`، أو أضف `--audio` لتوليد صوت الجديد فقط. السكربت يتحقق من أن كل كلمة في الجملة لها ترجمة، ويخبرك برقم السطر إن نقص شيء.

## الملفات

| المسار | المحتوى |
|---|---|
| `index.html`، `css/`، `js/` | الموقع |
| `stories/*.txt` | القصص (المصدر الذي تعدّله) |
| `data/bundle.js` | بيانات مولَّدة، لا تعدّلها يدوياً |
| `audio/` | الصوت المولَّد |
| `tools/build.py` | الفحص والبناء وتوليد الصوت |

## النشر

الموقع ملفات ثابتة، ويمكن رفعه كما هو إلى GitHub Pages أو Netlify أو Cloudflare Pages. ملف `.env` مستثنى في `.gitignore`.

## أصوات الشخصيات والراوي

معرّفات الأصوات الثلاثة (الراوي، أنثى، ذكر) في ملف `voices.json`، ومعها قائمة `cast` التي تحدد جنس كل شخصية.

في ملف القصة، اكتب اسم المتحدث بعد الترجمة، والجملة التي ليس لها متحدث يقرؤها الراوي:
```
> Salut, Léa ! Ça va ? | أهلاً يا ليا! كيف الحال؟ | Karim
```
وإذا كان شخص واحد يتكلم طوال القصة، فاكتب `@speaker Léa` تحت `@summary`.

لتوليد قصة واحدة فقط: `python tools/build.py --audio --only 01`

### الاستفادة من الصوت القديم

إذا أعطيت أحد الأدوار في `voices.json` معرّف الصوت القديم، وهو الموجود في `ELEVENLABS_VOICE_ID` داخل `.env`، فجمل هذا الدور تُقتطع من ملف القصة القديم (`audio/02.mp3` مثلاً) ولا يُعاد توليدها، فلا تستهلك رصيداً. ويُولَّد الصوتان الآخران فقط. هذا يعمل ما دام نص القصة وإعدادات الصوت لم تتغير منذ التوليد القديم.
